# Candidate Background (for Claude job-match evaluation)

> 把这份文件替换成你自己的信息。写得越具体，Claude评估匹配度时判断越准。
> 建议用英文写（因为抓到的JD大多是英文，两边语言一致，技术术语不会有翻译损耗）。

## Basic Info
- 工作年限、当前/最近职级
- 工作授权状态（是否需要sponsorship、绿卡/公民身份等）
- 期望地点（愿不愿意remote、愿不愿意搬迁）
- 学历背景

## Tech Stack / Core Skills
按熟练度/相关性从高到低列出你的核心技术栈。明确写清楚"有生产环境经验"和"只是概念性了解"的区别，这个区分对评估准确度影响很大。

## Hard Filters (auto-reject if not met)
写明确的判断规则，越具体越好，比如：
- "要求9年以上经验的职位直接拒绝"
- "要求特定语言/框架作为核心技能的职位直接拒绝"
- "职级明显低于我目前水平（entry-level/new grad）的职位直接拒绝"

## Nice-to-haves
非必须但有加分的项目，比如某个行业经验、某类系统经验等。写清楚这些是"部分匹配"，不应该被当成硬性gap扣分。
